# 미성달력

GitHub Pages에 게시하는 공동 달력입니다. [GitHub 저장소](https://github.com/b0816400/misung)를 사용하고, Supabase 데이터베이스에 달력 내역과 호실 정보를 저장합니다.

## 처음 설정하기

1. Supabase의 **SQL Editor**에서 [supabase-schema.sql](./supabase-schema.sql) 전체 내용을 실행해 달력 테이블을 만듭니다.
2. GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택하고 기본 브랜치의 `/(root)` 폴더를 게시합니다.
3. 사이트가 열리면 설정된 Supabase 프로젝트에 자동으로 연결됩니다. 연결에 실패하면 데이터베이스 테이블 생성 여부와 Project URL/공개 키를 확인하세요.

현재 Supabase Project URL은 `https://buwsyfnaymlpczltthkr.supabase.co`이며, Publishable key는 앱에 설정되어 있습니다. Publishable key는 브라우저에서 사용하는 공개용 키입니다. `service_role` 또는 Secret key는 절대 사용하지 마세요.

예상 GitHub Pages 주소: https://b0816400.github.io/misung/

## 사용 및 저장

- 날짜를 누르면 해당 날짜의 내역 창과 내역 추가 기능을 사용할 수 있습니다. 수입·지출 금액은 만원 단위로 입력하며, 예를 들어 `1.2`는 12,000원으로 저장됩니다. 기존 내역을 수정할 때도 입력란에 만원 단위로 표시됩니다.
- 상단의 **호실 설정**에서 거주자 이름, 전화번호, 입주일, 보증금, 월세를 호실별로 저장할 수 있습니다. 전화번호는 숫자만 입력해도 하이픈이 자동으로 붙으며, 모바일에서도 숫자 키패드로 입력할 수 있습니다. 보증금과 월세도 만원 단위로 입력합니다. 이 정보는 호실 모드와 날짜 상세 화면에 표시됩니다.
- 날짜 상세 창에서 기존 내역의 **수정**을 누르면 날짜, 호실/내용, 수입·지출, 금액, 메모를 변경할 수 있습니다.
- 월 제목 오른쪽에서 **달력 모드**와 **호실 모드**를 바꿀 수 있습니다. 호실 모드에서는 `전체`와 15개 호실 버튼 중 하나를 골라 이번 달 내역을 확인합니다. 호실은 404호 대신 406호를 사용합니다. 호실을 선택하면 그 호실 내역만 수입·지출 합계와 함께 표시되며, 내역을 누르면 날짜별 상세 창이 열립니다.
- 달력 아래에서 해당 월의 전체 내역을 날짜순으로 볼 수 있습니다.
- **호실별 내역 조회**에서 호실과 수입·지출·메모 종류를 선택할 수 있습니다. 최근 12개월이 기본이며 시작·종료 연도와 월(1월~12월)을 선택해 원하는 기간의 월별 내역을 조회할 수 있습니다. 검색에서 호실, 거주자 이름, 전화번호, 입주일, 보증금, 월세, 내역 제목이나 메모를 찾을 수 있습니다. 거주자 정보를 선택하면 해당 호실 내역을 표시하고, 입주일이 있으면 그 달부터 조회합니다.
- 공동 내역은 Supabase에 저장되며, 접속 중인 사람들의 화면에 변경사항이 실시간 반영됩니다.
- 기존 브라우저에만 저장되어 있던 내역은 연결 후 **기존 내역 함께 가져오기** 버튼으로 옮길 수 있습니다. 원래 브라우저 데이터는 삭제되지 않습니다.
- `file://`에서 쓰던 브라우저 내역을 GitHub Pages로 옮길 때는 기존 파일 화면에서 백업을 다운로드한 뒤, 공동 달력의 **백업 파일 가져오기**로 올립니다.

## 공개 범위 안내

이 방식은 비밀번호가 없으며, 웹사이트 주소를 아는 누구나 공동 내역을 읽고 추가·수정·삭제할 수 있습니다. 호실 설정에 입력한 거주자 이름, 전화번호, 입주일, 보증금, 월세도 누구나 조회하거나 수정할 수 있습니다. 공개해도 괜찮은 정보만 입력하세요. 
데이터베이스에서 삭제된 내역은 복구할 수 없습니다.
